# gdthumar2409.github.io

Public website for Train Yard Jam. Served by GitHub Pages at https://gdthumar2409.github.io/

| File | Used by |
|---|---|
| `app-ads.txt` | AdMob (must stay at the site root) |
| `train-yard-jam/chapters.json` | The game downloads this at start-up: chapters, difficulty and coin events |
| `train-yard-jam/privacy.html` | Privacy policy link for the Google Play listing |

Edit `train-yard-jam/chapters.json` and push to change chapters or run a coin event. Players get it on their next app start (allow about 10 minutes for caching). The field reference is in the game repository's README.
